# UI、交互与图表升级计划

## 已确认方向

- 保留品牌、暖红色、圆角、自定义导航和本地图标。
- 首页无预算突出本月结余；有预算突出剩余或超支。

5. 公共组件：颜色、字号、无阴影、触摸范围及动效。
