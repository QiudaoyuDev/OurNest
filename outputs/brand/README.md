# 咱家小账 · 小窝积蓄品牌资源

本轮采用用户确认的 Logo B 两层窝精修版：钱币代表收支，两层托举的窝代表共同生活。保留品牌暖红色，去掉原始三层窝中拥挤的底部线条。

## 资源选择

- `our-nest-app-icon.svg`：不透明、直角方形应用图标源文件。平台按需裁切，不预烘焙圆角。
- `our-nest-app-icon-{size}.png`：用于小程序入口、分享标识或需要实色底的默认头像。
- `our-nest-logo-transparent.svg`：暖红透明标志，适合浅色背景的登录页、首页品牌展示。
- `our-nest-logo-{size}-transparent.png`：对应透明 PNG；256 px 版本已接入小程序现有品牌图片路径。
- `our-nest-logo-reversed.svg` / `our-nest-logo-{size}-reversed.png`：暖白透明标志，适合品牌暖红底色。

所有 PNG 均提供 24、40、64、128、256、512、1024 px。小尺寸为评估用途；24 px 主要依赖整体轮廓识别，货币细节需真机确认。

## 使用建议

- 主色：`#F0442F`；暖白：`#FFF9F0`。
- 图形周围至少保留画布中已有留白，不拉伸、不加树叶、阴影或立体高光。
- 登录页建议组合中文名“咱家小账”与英文名“OurNest”；入口图标不加入文字。
- 推荐说明文案：“个人与家庭记账”；可选品牌文案：“一起记账，好好生活。”
- 此轮不交付字体转曲的定制字标。预览中的文字仅为排版参考。
- 这里只替换品牌意象，不替代分类、导航或操作用的 Remix Icon 线性图标。
- 货币元素可能偏向储蓄联想，避免收益、增值等不符合业务的理财表述。

## 重建与检查

独立 Python 渲染工具需要 `cairosvg` 和 `Pillow`，不引入小程序运行依赖：

```sh
python3 -m pip install cairosvg Pillow
python3 outputs/brand/export.py
```

脚本检查 SVG 结构、21 个 PNG 的尺寸、模式、背景与透明镂空。已检查 256 px 应用图标的实际导出效果。尚未进行微信真机视觉验证。

`our-nest-logo-256-transparent.png` 已复制到 `miniprogram/images/brand/our-nest-logo-256-transparent.png`；既有引用直接加载新图，不改页面布局、云函数或数据库，也不覆盖用户上传的个人头像。默认头像继续复用透明品牌标志，不另行切换成实色方形图标。

品牌造型与使用边界见 [UI 规范](../../docs/UI-GUIDELINES.md#品牌标志)，手工验收见 [回归清单](../../docs/REGRESSION.md#品牌-logo-替换)。

## 微信公众平台应用头像

1. 登录对应小程序的微信公众平台，在基本信息的头像设置中选择 `our-nest-app-icon-1024.png`。
2. 按后台当前文件大小、尺寸及审核要求确认上传，预览平台裁切；不要使用已预烘焙圆角或包含小字的版本。
3. 确认审核或保存状态，再检查微信搜索、最近使用和分享入口的实际显示；平台缓存可能不会立即刷新。

该操作需有权限的管理员手工完成，本次代码接入不代表平台头像已变更。尚未进行上传或发布。
