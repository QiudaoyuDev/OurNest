# 手工回归与发布验收

本文为待执行清单，不代表已经通过。使用隔离测试环境和测试数据，记录小程序版本、云函数版本、设备/基础库、账号角色、操作、预期与实际、日志及截图。不要将真实账单和用户信息提交仓库。

## 本地门禁

- [ ] `npm run verify`：格式、Lint、UI 规则、Node 测试、云函数语法。
- [ ] 关键视觉变化执行 `npm run visual:check`；分析专项执行 `npm run visual:analysis:check`，需要微信开发者工具及基线。
- [ ] 测试新增文件已列入测试命令，未用更新基线掩盖未知差异。

## 会话与环境

- [ ] 首次登录、重启恢复、昵称头像修改、退出再登录正常。
- [ ] 开发/体验连接 test；正式连接 production，缺少 ID 明确失败，不回退测试库。
- [ ] 切换账号、退出时在途旧请求不能写回；环境切换不复用旧会话。
- [ ] 同环境 key 更换实际环境 ID 后显式清理缓存再测，不能假定自动识别。

## 账本、权限与邀请（至少三个测试角色）

- [ ] 个人及共享账本创建、切换、名称备注编辑；Owner/成员/访客权限与 [业务矩阵](./BUSINESS-AND-IMPLEMENTATION.md) 一致。
- [ ] 访客不能绕过入口发写请求、导入；成员不能修改他人记录或预算。
- [ ] 邀请预览再确认，个人仅访客、共享可成员；过期、撤销、重复领取、已有角色不升级均正确。
- [ ] 两账号并发领取同邀请码至多成功绑定一人；原领取人退出后不能复用旧邀请。
- [ ] 成员/访客退出、Owner 移除和角色调整后云端立即撤权，历史记录保留。
- [ ] Owner 不能直接退出；所有权转移由目标成员确认，原 Owner 变成员，双方取消及旧邀请失效正常。

## 收支、分页与统计

- [ ] 新增/修改/删除、金额表达式、快捷金额、账户、备注标签及收入支出分类正常。
- [ ] 拒绝非法金额、无效公历日期、越权成员及跨账本分类。
- [ ] 两端同时修改产生版本冲突，不静默覆盖；网络失败先核查服务端结果。
- [ ] 至少超过一页的记录，检查同日记录稳定顺序、无遗漏重复、`hasMore`、筛选及范围汇总。
- [ ] 翻页期间另一端写入，快照变化后重置首屏，不混合旧新页。
- [ ] 首页月汇总、最近记录、明细范围金额与分析金额相符；空数据与错误不混淆。
- [ ] 周/月/年/自定义/全部、同期对比、跨年闰日、日历及分类账户下钻正确。
- [ ] 付款人、消费归属和录入人分别核对；未知及退出成员历史不被误推断。
- [ ] 家庭差额提示只核对现有前两名付款人的简化算法，不当作多人结算。
- [ ] Owner 设置/停用预算；账户去重、快捷金额限制及历史账户名称保留正确。

## 分类与恢复

- [ ] 扁平分类创建、重名限制、Owner 改名图标、成员不可编辑、其他分类受保护。
- [ ] 超过 250 条关联记录的分类迁移，反复 `hasMore` 后完成；不按同名历史记录误迁移。
- [ ] 迁移中尝试记账、分析、断网重进，栅栏与续传正常。
- [ ] 账本删除中断重试，阶段恢复且不可继续访问；单独核查操作状态和导入文件保留。

## 导入与反馈

- [ ] 模板、微信/支付宝代表文件及 CSV 编码；超过 5 MB/200 行、损坏文件、非法金额日期被拒绝。
- [ ] 失败交易排除、特殊方向人工确认、来源分类手动确认、疑似重复与确定重复区分。
- [ ] 固定选行分批导入，中断恢复不重写已处理行；并发同源导入无重复交易。
- [ ] 未开始取消、已开始不能取消、完成摘要重试及文件删除失败重试正常。
- [ ] 两用户/两环境恢复信息隔离；孤儿文件由管理员核查而非盲删。
- [ ] 反馈必选类型、文字及图片限制，历史仅返回本人反馈。

## 同步与设备

- [ ] 两账号共享：本机写后刷新，另一端前台约 2 分钟版本检查及手动同步可见变化。
- [ ] 后台停止计时、回前台检查；同步失败不提示完整同步成功，已成功写入不误报失败。
- [ ] 弱网、断网、超时、切账本在途响应不会污染当前界面。
- [ ] 真机小屏/全面屏安全区、键盘、长列表、图表切换销毁、Loading/Error/Empty/Ready 状态正确。

- [ ] production ID、同名云函数、云端依赖、20 秒超时及实际运行配置已核对。
- [ ] 集合、唯一索引、查询索引、存储/数据库安全规则及日志权限已在目标环境验证。
- [ ] 大数据统计耗时、比较 5000 条保护、导入事务与删除超时恢复有实测结果。
- [ ] 生产备份恢复演练、回滚方案和负责人已确认；没有将本地模拟通过当作上线证明。
