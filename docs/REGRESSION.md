# 发布前回归清单

每次准备在微信开发者工具上传前，先运行：

```powershell
npm run verify
```

然后在目标测试环境完成与改动相关的手工回归。

涉及 UI 时额外运行：

```powershell
npm run ui:check
npm run visual:check
```

视觉基线只在人工确认变更正确后通过 `npm run visual:update` 更新。

## 核心流程

- [ ] 登录：首次登录、再次进入、退出后重登及当前账本恢复正常。
- [ ] 账本：创建个人/共享账本、切换账本；Owner 编辑名称和备注后当前页面、当前账本缓存及另一成员同步结果正确，非 Owner 无编辑入口且接口拒绝越权。
- [ ] 同步：另一成员修改共享账本记录或分类后，自动同步到期与“我的 → 同步数据”均能刷新当前页面；自动同步无变化时不重复加载业务数据；手动同步即使版本无变化，也重新核对账号、账本和当前账本分类，全部完成后才提示成功。
- [ ] 记录：新增、查看、编辑、删除收入和支出；首页与分析统计同步更新。
- [ ] 首页：收入、支出、结余、本月记录数、支出最多、支出最大和月预算均按当前账本当月全部记录计算；超过 50 条和 100 条时仍与分析页一致。
- [ ] 最近记录：始终显示当前账本全部历史中最新 10 条；当月不足 10 条或无记录时正确跨月、跨年展示。
- [ ] 首页无支出：当月无记录或仅有收入时，“支出最多”和“支出最大”均显示 `-`，不显示默认分类、零金额或 `¥-`；有支出时正常显示。
- [ ] 明细：切换账本、月份和类型筛选；触底分页无重复或遗漏。
- [ ] 分析：周、月、年、账本和收支类型快速切换不会被旧请求覆盖；图表与分类、账户、排行、预算、同期对比和无数据状态与账目一致。
- [ ] 月历选择日期后分页加载当前收支类型的记录；分类和账户下钻的金额与笔数对应，分类名称相同但 ID 不同、空账户和字面同名账户不串数据。
- [ ] 周跨年、闰月、月末同期截断和当前未结束周期显示正确；共享账本的录入人、付款人和消费归属维持原有口径，访客只能查看。
- [ ] 320/375/390/430 宽度、iOS 和 Android 分别核对筛选栏、分区吸顶、长文字、图表触摸、滚动和底部安全区；记录实际设备和结果。
- [ ] 月历核对今天、选中、未来日期及有金额日期的区分，万元和长金额显示不挤压格子；选中后合计显示精确金额。
- [ ] 手动滚动后反复点击“小结、分类、账户、共享支出”，各标题始终位于吸顶分区导航下方；末尾内容不足一屏时也能定位。
- [ ] 上下滑动经过分类环图，图表不遮住导航和其他内容；点击扇区仍能展开对应分类。
- [ ] 排行、分类预览和过滤明细均显示正确的分类图标、颜色和对齐；缺失图标使用默认图标。

分析页视觉场景使用 `npm run visual:analysis:check`，首次建立基线用 `npm run visual:analysis:update`；通过 `TL_WECHAT_CLI` 指定微信开发者工具 CLI。脚本复制源码到临时项目并使用合成数据，不读取用户账目；执行前开启开发者工具服务端口。确认输出截图后才使用基线作为回归依据。

- [ ] 趋势交互：周柱进入对应日期，月柱切换对应月份，年柱先显示金额再进入对应月份；趋势明细中的金额与柱图和账目汇总一致。
- [ ] 预算和账户：权限、禁用、保存与重新进入后的数据恢复正常。
- [ ] 分类：新增、编辑、删除；删除后关联记录迁移到“其他”。
- [ ] 邀请：成员和访客领取正常；写入、编辑、删除、导入和导出权限符合角色规则。
- [ ] 个人资料与反馈：修改后可恢复；反馈创建、图片和历史列表正常。
- [ ] 账本删除：测试环境中验证中断、重试、完成状态及当前账本恢复。

## 组件整理回归

- [ ] 首页选择账本会切换当前账本；明细、分析中的选择只切换查看范围，选中状态、失败重试、账本设置和新建入口正常。
- [ ] Loading 与 Toast 合并后，四种提示、遮罩拦截、重叠请求、页面跳转和返回时的显示及清理正常。
- [ ] 预算条比例为 0、正常值、超预算、异常值时正确显示；各页面骨架及未知类型回退正常。
- [ ] 分析模块：周月年趋势、收入及支出分类排名和自定义范围分析均来自接口真实数据；跨年、闰月和空数据不出现示例记录。

## UI 与状态

- [ ] Loading、Empty、Error、Ready 互斥，不闪现初始化业务数据。
- [ ] 全局 Toast 的 success / warning / error / info 文案、颜色和图标正确；页面跳转后短提示正常消失。
- [ ] 下载模板、删除账本、移除成员和准备分享时，全局 Loading 文案正确，成功或失败后均关闭遮罩。
- [ ] 首屏 Loading 只显示骨架和稳定壳层，不提前显示 Ready 内容或底部业务元素。
- [ ] Tabbar、页面操作栏和 Bottom Sheet 不遮挡滚动内容。
- [ ] 每个页面只有一个底部安全区负责人；刘海屏底部安全区、长文本和窄屏布局正常。
- [ ] Bottom Sheet 遮罩关闭、内部点击、长列表、加载和重试正常。
- [ ] 数字键盘打开、关闭、提交和删除时层级正确，按钮、遮罩与键盘互不遮挡。
- [ ] 除 Tabbar 外无阴影；渐变端点与相邻背景自然衔接。
- [ ] 只读、禁用、保存中和删除中状态与权限一致。

## 品牌 Logo 替换

- [ ] 重新编译后，登录页、首页、导航栏和创建账本页展示暖红“钱币＋两层窝”，无番茄或缺图；原布局、图片容器尺寸与动画保持不变。
- [ ] 公共 Empty 和 Error 状态使用新标志，错误态原透明度正常；Loading 与 Ready 的状态互斥不变。
- [ ] 个人资料、资料编辑、成员列表、首页记录和记录详情中的系统默认头像为新标志；圆形裁切不切掉钱币和窝，已上传的自定义头像保持原样。
- [ ] 已登录旧用户重新进入、退出后登录和新用户进入均能加载当前打包资源，不需要清空账本数据或改写用户资料。
- [ ] 在模拟器及真机检查小尺寸线条、透明背景和浅暖底色对比度；人工确认截图差异后再决定是否更新视觉基线。
- [ ] 如需更换微信公众平台应用头像，手工上传 `outputs/brand/our-nest-app-icon-1024.png`，按后台当前尺寸及审核要求确认，并核对微信搜索及最近使用入口；仅代码替换不代表平台头像已更新。

## 收支分类明细联动

- [ ] 周、月、年分别切换收入和支出，点击扇区或分类行展示最近 3 笔；“其余分类”只展开剩余分类，不作为真实分类查询。
- [ ] 同名不同 ID、同名不同父分类的历史记录分别统计；预览、完整明细的金额、笔数与原统计一致。
- [ ] 弱网快速切换分类、账本、周期和收支类型，旧请求不能覆盖新状态；数据变更导致金额或笔数不符时提示刷新。
- [ ] 分类行与扇区均支持点击展开、再次点击折叠；加载中折叠后迟到的请求不得恢复展开。收起隐藏分类时同步关闭其中的明细。
- [ ] 不同分类显示各自配置图标，同一分类行与展开的最近记录图标一致；修改分类图标后、无 ID 历史记录、配置不存在和无效图标均按回退规则显示。
- [ ] 访客仅可查看预览和详情；在模拟器和真机检查长备注、分类文字、滚动与图表层级。

## 中性入口文案

- [ ] 导航品牌显示 OurNest；登录介绍显示“记好每一笔，生活更有数。”；编辑金额键盘标题显示“记一笔”；更新日志副文案显示“查看最近更新”。更新日志仍为预留入口，不将文案调整误认为日志页面已实现。
- [ ] 窄屏及大字体下品牌、标语和按钮不重叠；登录截图变更需人工确认，不能直接更新基线掩盖差异。

## 正式版额外确认

- [ ] `production.id` 已配置，且同名 `ourNest` 已部署到生产环境。
- [ ] 核对 `ourNest` 的运行时、超时、权限及外部触发依赖，检查 `ourNest` 请求日志与 `ourNestError` 错误日志。
- [ ] 默认头像使用可加载的 `our-nest-logo-256-transparent.png`；导入模板可生成、下载和打开。
- [ ] 生产集合、索引和安全规则已核对。
- [ ] 仓库中没有测试数据、用户数据或生产密钥。

## 缓存与数据一致性回归

- [ ] 本地缓存使用 `ourNestAuth`、`ourNestLedgerCache`、`ourNestCategoryCache`；无有效缓存时可完成登录并重新加载数据。
- [ ] 本地持久化只保留登录资料、账本和分类；登录快照不保存当前账本对象或统计，记录列表不写入本地缓存。
- [ ] 明细月总收入、总支出和笔数来自接口完整汇总；一个月超过 50 条时，首屏 30 条及后续分页均不改变月总数，分页游标正常。
- [ ] 从明细打开编辑再直接返回，原页面已加载记录和位置保留；修改成功后重新查询，最后一条删除后显示空状态。
- [ ] 编辑和详情每次进入均查询最新记录；保存/删除未完成时没有成功提示或返回，失败保留输入并支持重试，冲突不覆盖他人修改。
- [ ] 分析重新进入、切换月份/年份和账目变动时重新读取云端；旧月份的慢请求不会覆盖新月份。
- [ ] 分类冷启动等到真实返回；修改或共享账本版本变化使分类失效，下次读取重新查询；已移除账本的分类一并清除。
- [ ] 手动同步遇到账号、账本或分类任一步失败，不提示成功、不更新成功时间，允许重试；无账本时仍可完成账号和列表同步。
- [ ] 退出、切换账号/环境后分类内存和本地缓存隔离，旧会话未完成的登录/账本/分类请求不得重新写入缓存。
- [ ] 测试环境使用两个微信账号：成员 A 修改共享账目/分类，成员 B 自动同步或手动同步后再进入相关页面，列表与统计保持一致。

## 访客查看记录

- [ ] 访客从首页最近记录或明细进入只读详情，金额、分类、账本、账户、记录人、备注和标签正常显示，无重选分类、保存、删除操作。
- [ ] 明细查看只读账本时，即使当前记账账本可写，点击该记录仍进入只读详情；普通可写账本保持原编辑入口。
- [ ] 底部“＋”始终保留并可点击，初次进入及切换到访客账本后立即置灰，不依赖点击；当前账本只读时提示“当前账本为只读账本，访客仅可查看”，不打开新增流程；切换至可写账本后恢复记账。
- [ ] 通过旧链接直接进入编辑页时，以 `record/get` 返回的角色为准，将访客转到只读详情；加载期间、只读状态下不显示编辑表单和底部操作，不发送保存/删除请求。
- [ ] 测试环境访客直接调用新增、修改、删除接口仍被云端拒绝；成员编辑自己的记录、创建者管理全部记录正常。

- [ ] 记账、导入、预算和快捷金额等因访客权限被拦截时，均使用同一提示“当前账本为只读账本，访客仅可查看”，不出现各入口自定义的不同文案。

## 统计、导入与家庭归属回归

- [ ] 在测试环境准备独立账本及测试账号，操作前导出 `ledgers`、`categories`、`records`、`ledgerOperations` 并备份已部署云函数与云存储规则；核对环境 ID，禁止对生产环境执行测试。记录备份时间与恢复演练结果。
- [ ] 分类改名后，按分类 ID 下钻的完整分页总额与统计一致；同名但不同父分类的历史未关联记录分开。删除分类时准备超过 250 条记录，模拟请求中断并继续；核对每条记录只迁移一次，进行中不能选择该分类，且旧编辑版本不能覆盖迁移。
- [ ] 选取两个非连续月份、跨年月份、两个年份及当前未结束周期，核对收入、支出、结余、分类专项和明细；金额对账到分，未来日期不纳入当期分析，零基数不显示无穷百分比。
- [ ] 使用合成或脱敏微信、支付宝 CSV/XLSX，核对成功收支、特殊交易人工确认、失败排除、来源交易号、跨来源疑似重复及明确分类选择；重复提交和网络中断重试不产生重复记录。
- [ ] 两个成员与只读访客使用同一共享账本：核对代记、代付、个人消费、公共及多人消费、未知历史数据；付款、消费和录入三种视角分别下钻并与账本总额核对，访客不能写入或导入。
- [ ] 云存储规则先备份现有配置，再在测试环境验证两个账号对各自及对方的账单文件上传、覆盖、读取和删除权限，同时验证头像、反馈图片和模板；规则候选与实际部署状态分别记录，异常时恢复已备份规则。
- [ ] 云函数回滚时先确认测试环境及备份版本，恢复原 `ourNest` 代码及依赖；如已产生测试写入，按导出的同环境备份验证恢复方案，不向生产库导入测试数据。涉及真实用户数据的删除或覆盖须先完成独立备份和恢复演练。

## 快捷记账：同页分类与金额

- 从 Tabbar、首页新增、明细空态、创建账本后入口进入记账页，不先进入分类页；只读账本仍阻止新增。
- 初始显示“请选择分类”，选择分类前不显示录入面板；所有可记账分类平铺、选择分类不跳页。选中项显示浅底和边框，底部面板分类信息同步；选择同名不同 ID 分类时仅目标高亮。切换支出/收入或删除选中分类后，高亮与分类值一并清空，金额、备注、日期、账户和家庭归属保持。
- 分类加载中、加载失败和空列表分别显示对应状态；失败可重试；分类管理仅从“我的”进入，重新进入记账页后更新分类，已删除的选择必须清空。
- 新增记账填写金额或备注后点击页面返回，应确认放弃；取消保留输入，确认后返回，无输入时直接返回。
- 家庭账本成员加载/失败与归属校验仍生效；完成键直接保存并返回，编辑旧记录与只读详情跳转均正常。
- 新增及编辑成功直接返回，连续记账成功重置本笔字段并保留分类、日期、账户与家庭归属，录入面板保持打开，均不显示成功文字提示；弱网期间保留保存中状态且不重复提交，失败仍显示错误并保留输入，删除成功反馈保持。
- 窄屏及大字体下，分类可滚动、录入面板可操作；共享支出直接显示付款人、消费归属和消费成员，选择时不丢失输入。
- 在 iPhone 16 Pro、iPhone 17 Pro 的模拟器及真机检查安全区、按键尺寸、分类滚动、备注调起系统键盘时的遮挡、失焦后数字键盘恢复，以及编辑记录标签输入；验证加减表达式、无效输入、重复点击和网络失败后重试。

- 新账本默认支出包含参考分类和交通项目；打开已有账本不因新模板额外新增分类。
- 火车高铁快捷金额为 373.5、356.5、265、432.5；打车沿用当前账本配置或默认金额，切换分类即时更新。

- [ ] 自定义和累计分析：检查单日、跨月、跨年、闰日和空账本的折线与趋势明细；累计跨度为 24、25 个月时分别按月、按年显示。点击数据点、趋势明细和收入/支出分类后，记录范围与汇总一致；图表失败可重试且明细仍可查看。

- [ ] 邀请码：新用户不创建账本即可输入邀请码加入并进入账本；已有账本用户加入后可选择是否切换。共享账本分别邀请成员和只读访客，个人账本只能邀请只读访客。验证复制、大小写与分隔符、过期、已使用、重复提交、双账号并发领取、限频和分享卡片。
- [ ] 测试环境多人协作：分享链接在已登录和未登录时均先预览再确认；访客使用成员邀请不升级、不消耗新码。验证按选定角色生成、撤销与并发领取；转移后旧邀请失效，即使所有权再转回也不恢复。
- [ ] 测试环境验证成员、访客主动退出及 Owner 移除、角色调整；历史记录和创建者保留，退出或降权后云端拒绝无权操作。并发加入及移除时不丢失其他成员。
- [ ] 测试环境验证 Owner 向现有成员发起转移，接收、拒绝、取消及目标退出或降权后的失效；确认原 Owner 成为成员，唯一 Owner 不可退出，原邀请失效。测试前备份数据和云函数，并准备回滚。
- [ ] 修改昵称和头像保存返回“我的”后立即显示新资料；分别验证默认头像、云头像及保存失败情形。
