问题 1：弹窗遮罩层级穿透与三层叠加
高频阻断

真机现象：点击切换账本时，顶部的周度/年度标签像浮在遮罩上被选中一样；点击“更多”弹窗后再点击账本切换，界面出现三层叠加混乱。

Before 根因剖析

1. .analysis-header 硬编码了 z-index: 100，高于遮罩层 --tl-z-overlay: 90，导致顶栏穿透遮罩不被调暗。

2. switchLedger() 唤起账本抽屉时未互斥关闭 isModeSheetVisible，导致多重弹窗并存。

After 解决方案

1. 将 .analysis-header 的 z-index 修正为 var(--tl-z-sticky) (20)，全局遮罩层 (90) 自然盖住顶栏。

2. 顶栏直接升级为 5 选项一键平铺 Tab，彻底淘汰“更多”弹窗；且调用 switchLedger 时自动关闭所有其他 sheet。

问题 2：点击“累计”报错“分析数据加载失败”
核心 Bug

真机现象：选择累计分析时，直接报错弹出“分析数据加载失败，请检查网络后重新加载”。

Before 根因剖析

后端 analysis.handler.js 在 mode === 'all' 时返回 range: { start: "", end: "", label: "全部时间" }，前端 analysis-contract.js 的 assertDate(range.start) 强制要求 YYYY-MM-DD，抛出 ANALYSIS_CONTRACT_INVALID 异常触发捕获报错！

After 解决方案

在契约校验中为 mode === 'all' 或全空 range 提供合规旁路放行，并完善累计总览、历史资产走势及分类总资产聚合展示，彻底修复崩溃！

问题 3：走势图空白、排版纯黑、日期选择重复
观感不佳

真机现象：上面有日期区间，下面又出现“选择日期范围”卡片；走势图呈现大片白屏空白；趋势明细是纯黑色字、观感极差。

Before 根因剖析

1. index.wxml 在自定义模式下重复渲染了顶部 rangeLabel 和下方的 custom-range 卡片。

2. 走势图使用 ec-canvas 且强制 force-use-old-canvas="true"，在新版微信中 Canvas 1D 废弃导致白屏。

After 解决方案

1. 整合为顶部卡片内的“快捷预设胶囊 (近7天/近30天) + 自定义时间对齐框”，删除冗余卡片。

2. 引入轻量级原生 CSS 柱状走势图（与周/月小结完全同款），零延时秒开、支持柱体点击高亮，彻底杜绝白屏。

问题 4：日期断裂换行、金额排版不对称
排版缺陷

真机现象：11-11 被压扁折成 11- 和 11 换行显示；金额是单行字符串拼凑（收入 ¥5000 · 支出 ¥129.90 · 结余...）无对齐；年度列表中“2月”被顶部遮挡。

Before 根因剖析

1. .dashboard-row 采用 flex 两端对齐，左侧日期未设固定宽度且未禁止换行，被右侧长文本压缩折断。

2. 未使用语义化颜色（收入绿、支出红），所有文本全黑无视觉层级。

After 解决方案

1. 设立固宽 date-badge 并配置 white-space: nowrap，杜绝任何断行。

2. 升级为结构化三列表格微卡片：收入（绿色）、支出（暖红）、结余（加粗深色），有交易的行赋予高亮衬底，空交易行灰化收敛，清晰整洁！
