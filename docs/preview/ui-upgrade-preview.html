四大核心升级支柱
1. 微环境光与呼吸感 (Ambient Glow)
打破“绝对零阴影”造成的纸片黏连感，引入 1px 极微透光描边 + 柔和双层漫反射柔影，让卡片温润浮现于羊绒暖白底上。
2. 黄金 3 秒数据层级 (Glance Hierarchy)
告别“收/支/余三列等大平铺”。以 “本月可用预算” 作为超大 Hero 锚点，收支归纳为左右双胶囊，重要数据一眼捕获。
3. 色彩解耦与心理降噪 (Chroma Decoupling)
暖红不再漫天飞！将“主操作红”与“支出赤陶”分离，引入 柔底微衬色（Soft Pastel Containers），消除大面积记账焦虑。
4. 触感微交互 (Tactile & Kinetic)
键盘键位下沉弹性阻尼、平滑抽屉弹出、浮动记账 Hub、数字即时运算，让每次记账都充满手感与愉悦。
💡 提示：可以在右侧手机屏幕中点击底部各 Tab、点击中间加号 ➕ 唤起微触感记账键盘，实时测试交互体验。
