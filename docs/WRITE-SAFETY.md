# 写操作一致性策略

- 云函数对每个写操作重新读取用户和账本并判定角色，客户端参数不作为权限依据。
- 记录写入校验金额、类型、日期和标签数量；分类删除和账本删除校验目标 ID。
- 邀请领取应使用 CloudBase 事务或条件更新，确保令牌至多绑定一个 OpenID，并保持令牌绑定与成员写入一致。
- 账本删除、分类迁移等操作可能超过单事务容量，必须采用“标记进行中 → 分批处理 → 完成确认”的可恢复、可重试流程，不能假设存在无限事务。
- 多步操作需考虑中断、重复请求和幂等性；失败后不得留下对用户不可解释的半完成状态。
- 涉及删除、迁移、权限或生产数据的变更，先在测试环境演练，并准备备份和回滚方案。

## 分析快照前置条件

`syncRevision` 仅在影响统计、图标或权限的业务变更与 revision 同一事务提交后，才能作为记录分页快照的围栏。记录 CRUD、预算、账户、快捷金额、邀请创建和分类阶段切换均在事务内重读账本与权限并递增版本；分类迁移等超事务容量流程仍以“标记进行中 → 分批处理 → 完成确认”推进，不能把批处理中状态标记为稳定快照。

分析和记录列表在读取前后检查账本权限、版本及分类迁移标记，版本失效时分别返回 `ANALYSIS_SNAPSHOT_CHANGED` 或 `RECORD_SNAPSHOT_CHANGED`；分页冲突后客户端重新获取首屏。旧账本缺失版本时在事务内重新授权并初始化，不能覆盖并发更新。由于默认分类修复及部分分类写入尚未与版本原子提交，这些围栏仍有已知盲区，不构成完整稳定快照保证；上线前必须修复并完成真实云端并发验证。

分析不得以 revision 跳过读取或缓存完成结果：当前只使用失效通知重新读取。任何 mutation 响应若向客户端提供账本 ID 或 revision，值必须来自服务端在授权后实际写入的账本，不能由客户端 payload 推断。

- 生产备份、迁移与恢复流程尚未落地，记录在 [`plan/PENDING.md`](../plan/PENDING.md)。

- 模板导入服务端仅下载 `imports/<调用者 OpenID>/<文件名>` 路径的云文件；路径检查不能代替云存储权限规则。测试及生产环境必须分别验证用户无法写入或读取其他用户目录，部署前需配置相应规则。导入使用事务将记录与批次进度一起提交，单次最多 10 行；重试必须使用原批次和原选择。分类删除导致导入中断时，用户可明确选择将未处理行归入未关联的“其他”，服务端保留已处理行的选择并通过事务记录恢复状态，重复恢复可安全重试。文件引用计数与待删除状态的具体保留策略见数据文档；发布前须在测试环境验证事务冲突、断网恢复、权限撤销、文件清理及云存储规则。
- 导入、记账和编辑事务内重新读取账本与分类；分类删除标记、记账和编辑事务共同更新账本同步版本，利用写冲突避免快照隔离下的交叉提交。迁移处理中记录 `categoryDeletionId` 并暂停账本写入，清理完成后与操作完成状态一起解除；记录编辑在事务中校验版本，分类迁移同步递增记录版本。仍需做真实并发演练，不能将本地模拟视作 CloudBase 隔离性证明。
- 分类新建和编辑也在事务中检查迁移标记并更新账本版本；创建一级分类及其默认子分类在同一事务完成。分类读取期间的默认分类修复仍使用独立数据库操作，修复开始后与删除标记并发时存在竞态，尚不能将该路径视为已通过并发验收。
- [`config/storage-rules.candidate.json`](../config/storage-rules.candidate.json) 是待演练的云存储规则候选，不会自动部署：头像和模板允许读取，账单与反馈图片仅创建者可读，客户端仅可写入自己创建的头像、账单和反馈图片。规则基于 [CloudBase 云存储安全规则](https://docs.cloudbase.net/storage/security-rules)，不得直接覆盖现有环境配置；先备份现有规则并盘点其他路径，在测试环境确认上传、覆盖、删除及双账号读写边界后再决定部署与回滚。路径含 OpenID 不能替代创建者所有权校验，不能声称规则已经生效。
- 新导入先由服务端签发绑定调用者和账本的随机上传路径，预览前及事务内均校验凭证；凭证领取后绑定完整文件 ID。上传后预览失败可安全放弃未领取凭证并清理文件，已领取凭证必须通过批次流程处理。云函数使用管理员权限下载文件，随机路径凭证本身不等同于核验云存储文件创建者；存储规则与跨账号访问仍须在测试环境验证后才能视为安全验收完成。
- `ledgerOperations` 中的上传凭证、导入批次和文件引用标记不得由客户端直接读写；[`config/ledger-operations-rules.candidate.json`](../config/ledger-operations-rules.candidate.json) 为拒绝客户端直接访问的待演练规则，不会自动部署。应用只能通过云函数访问这些信息；测试环境须验证两个账号及未登录客户端均无法直接查询或修改该集合，并先备份现有规则。
