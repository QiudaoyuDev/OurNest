# 写入、权限与恢复边界

## 服务端授权

身份来自微信云上下文，账本权限以服务端重新读取的 `ownerOpenid`、`memberOpenids`、`viewerOpenids` 为准，不以客户端角色或展示用成员数组授权。Owner 可管理全部记录，成员只能编辑/删除自己录入的记录，访客不可写入或导入。退出及移除不删除历史记录。

接口和字段见 [API](./API.md)、[数据契约](./DATABASE.md)，实际事务见 [账本 Handler](../cloudfunctions/ourNest/handlers/ledger.handler.js)、[记录 Handler](../cloudfunctions/ourNest/handlers/record.handler.js)、[分类 Handler](../cloudfunctions/ourNest/handlers/category.handler.js)。

## 不同写入不能采用相同重试策略

| 操作         | 当前保障                                     | 失败后的处理                                     |
| ------------ | -------------------------------------------- | ------------------------------------------------ |
| 普通新建记录 | 记录与账本版本事务提交，不提供通用请求幂等键 | 网络失败不代表未提交，先查询确认，不盲目重复创建 |
| 编辑记录     | `syncVersion` 检查并在事务中提交             | 版本冲突重新读取，不覆盖他人修改                 |
| 删除记录     | 传入非零 `syncVersion` 时检查版本            | 重新确认记录及当前版本，不声称所有删除强制带锁   |
| 邀请领取     | 领取状态与成员关系同事务                     | 原领取人仍有角色时可幂等重试，退出后不能复用     |
| 分类删除     | 操作状态、写入栅栏、有限批次迁移             | 按 `hasMore` 继续相同操作，勿手工清标记          |
| 账本删除     | 标记及阶段进度，末阶段事务确认               | 重试继续阶段；需要真实超时演练                   |
| 导入         | 每事务最多 10 行，记录、进度、版本原子提交   | 使用同批次和固定选行继续，不另建批次替代恢复     |

API 服务没有自动网络重试。写入已成功但刷新失败时，应提示同步问题，不把成功写入误报为业务失败。

## 分类迁移

Owner 删除非 `isOther` 分类时，先保存操作状态并标记分类及账本，按准确 `categoryId` 将记录迁移到同类型其他分类。每次最多 5 × 50 条，更新分类快照并清空旧父分类快照；不按历史名称推断、不递归处理旧子类。

达到批次上限可能仍返回 `hasMore: true`，即使刚好迁完也需再调用确认。迁移期间相关记录写入、导入和读取分析受栅栏保护。清理事务删除分类、完成操作并清除账本标记；中断后从原分类删除入口继续。

## 账本删除

阶段为 `records → categories → invites → ledger → complete`。初始标记和操作状态同事务；最终删除账本与完成操作同事务。阶段查询每次 100 条，但服务端循环清理整阶段，**不是每请求只删 100 条的客户端分页协议**，仍可能遇到云函数超时。

当前不删除 `ledgerOperations` 和导入文件；完成后只修正发起人的当前账本，其他参与者依赖重新同步。删除前必须确认操作范围与备份，不应宣称业务删除等于所有关联文件彻底清除。

## 导入与文件

凭证绑定用户、账本和上传路径，服务端重新验证文件 ID、大小、哈希及当前权限。首次提交后选行固定；来源身份标记防止可靠交易号的同源重复写入，但不是任意记录的全局去重。

未开始预览可取消；已开始批次需继续。最后文件引用释放后尝试删除文件，失败保存待清理状态。历史无引用标记及客户端未收到文件 ID 的孤儿文件需管理员核查，不能随意批量清除。批次摘要、文件引用、来源去重标记当前长期保留。

## 邀请与所有权

邀请码至多绑定一名领取人，24 小时有效；已有角色不升级、不消耗新邀请。撤销不适用于已领取邀请。共享账本所有权由目标成员接受，旧 Owner 成为成员，`ownerEpoch` 递增使旧邀请失效；Owner 不可直接退出。

## 运维与隐私

- 本地测试不能证明 CloudBase 真实事务冲突、索引、安全规则和文件删除正确。
- 所有删除、迁移和生产操作应先测试环境演练，并准备备份、恢复验证及回滚方案；本仓库不提供已完成生产备份恢复的证明。
- 请求错误日志包含字段名脱敏和截断后的 payload，仍可能含备注、反馈等业务内容；日志、操作集合和导入文件需控制权限及保留期。
- 本轮仅维护文档，不执行部署、清库、迁移、云文件清理或生产写入。
